# NYC Airbnb Data Exploration

Exploratory analysis and cleaning of the `AB_NYC_2019.csv` dataset (NYC Airbnb listings, 2019).

## Files

- `AB_NYC_2019.csv` — original dataset (not modified).
- `AB_NYC_2019-clean.csv` — cleaned output, generated by the notebook.
- `explore.ipynb` — loads the data, checks shape/dtypes, checks for duplicate rows, converts `last_review` to a date, cleans the data, and saves the result.
- `summary_stats.ipynb` — quick summary numbers and distribution tables.
- `visualizations.ipynb` — comprehensive, clean exploratory data visualizations with developer-focused explanations and engineering takeaways below each chart.
- `generate_visualizations.py` — automated script to generate and execute the visualization notebook.

## Cleaning steps applied

- Dropped exact duplicate rows (none found).
- Dropped rows with `price == 0` (invalid listings).
- Converted `last_review` from text to `datetime64`.
- Filled `reviews_per_month` with `0` where there are no reviews.
- Filled missing `name` / `host_name` with `"Unknown"`.
- Left `last_review` as `NaT` where a listing has never been reviewed.

## Usage
 
1. Run `explore.ipynb` to clean the raw data and produce `AB_NYC_2019-clean.csv`.
2. Open `visualizations.ipynb` to inspect all charts and developer explanations, or run `python generate_visualizations.py` to rebuild and execute it.
