# module4 — NYC Airbnb Data Exploration

## Files
- `AB_NYC_2019.csv` — original dataset, never modified.
- `AB_NYC_2019-clean.csv` — cleaned output, generated by `explore.ipynb`.
- `explore.ipynb` — loads data, checks shape/dtypes, checks duplicates, converts `last_review` to date, cleans the data, saves the cleaned CSV, documents the schema.
- `summary_stats.ipynb` — loads the cleaned CSV and computes summary numbers (distribution by `neighbourhood_group`/`room_type`, min/max/mean/median for `price`/`minimum_nights`/`number_of_reviews`, avg/median price by borough) as prep for Day 2 visualizations.

## Data schema (df, cleaned)
| Column | Data type | Meaning |
|---|---|---|
| `id` | int64 | Unique listing ID |
| `name` | str | Listing title |
| `host_id` | int64 | Unique host ID |
| `host_name` | str | Host's display name |
| `neighbourhood_group` | str | NYC borough |
| `neighbourhood` | str | Specific neighbourhood |
| `latitude` / `longitude` | float64 | Listing coordinates |
| `room_type` | str | Entire home/apt, Private room, or Shared room |
| `price` | int64 | Nightly price (USD) |
| `minimum_nights` | int64 | Minimum nights per booking |
| `number_of_reviews` | int64 | Total review count |
| `last_review` | datetime64 | Date of most recent review (`NaT` = never reviewed) |
| `reviews_per_month` | float64 | Average reviews per month |
| `calculated_host_listings_count` | int64 | Host's total listing count |
| `availability_365` | int64 | Days available out of next 365 |

## Cleaning steps already applied (do not redo/duplicate)
- Dropped exact duplicate rows (0 found).
- Dropped 11 rows with `price == 0` (invalid).
- Converted `last_review` from text to `datetime64`.
- Filled missing `reviews_per_month` with `0` (listings with no reviews).
- Filled missing `name` / `host_name` with `"Unknown"`.
- Left `last_review` as `NaT` where a listing has never been reviewed — don't fabricate dates.
- Result: 48,895 → 48,884 rows.

## Conventions for this project
- Never overwrite `AB_NYC_2019.csv`; all cleaned/derived output goes to new files.
- Notebooks use a markdown cell above each code cell explaining what it does and why.
